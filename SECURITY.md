# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately via GitHub:
**Security → Report a vulnerability** ([private vulnerability reporting](https://github.com/AdanedhelWrites/tech-radar/security/advisories/new)).

Include affected endpoint/component, reproduction steps and impact. You will get a first response within 7 days.

## Supported Versions

Only the latest `main` branch is supported.
